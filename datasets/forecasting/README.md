# Explicit synthetic forecasting example

`orders.csv` contains 140 labelled demonstration sale rows from 2026-06-11 through 2026-10-28, using retail sample customers C1/C2 and product P1. Import the retail customers, suppliers and products first, then preview and explicitly confirm this CSV in a **separate demonstration business**. No file is imported automatically.

In Forecasts & risk, choose the exact date range, daily aggregation, seven periods, and **Labelled demonstration records only**. Confirm coverage only for this complete synthetic window. Results demonstrate the model workflow; they do not establish real-business forecast accuracy. These sales do not automatically reduce stock. See docs/forecasting-api.md for definitions and limitations.
